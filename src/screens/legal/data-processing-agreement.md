# Data Processing Agreement

**Studio by Scientist**
Last updated: May 2026

## 1. Scope

This Data Processing Agreement ("DPA") applies to the processing of personal data by Studio by Scientist ("Processor") on behalf of the church or organization ("Controller") using the App.

## 2. Data Processed

The Processor processes the following categories of data on behalf of the Controller:
- Church staff email addresses
- Church profile information (name, location, size)
- Service session activity logs

## 3. Purpose of Processing

Data is processed solely to provide the Studio by Scientist service, including authentication, session management, and AI-assisted features.

## 4. Sub-processors

The following sub-processors are engaged:
- **Supabase** — database and authentication
- **OpenAI** — audio transcription and Bible reference detection

## 5. Security Measures

We implement appropriate technical and organizational measures to protect personal data against unauthorized access, loss, or destruction.

## 6. Data Retention

Data is retained for the duration of the active account. Upon account deletion, data is removed within 30 days.

## 7. Controller Rights

The Controller may request access to, correction of, or deletion of personal data at any time by contacting support@studiobyscientist.com.

## 8. Contact

support@studiobyscientist.com
